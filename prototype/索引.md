## 助理主流程

| 流程 | 入口 | 说明 |
| --- | --- | --- |
| 添加助理 | 右上角「添加助理」 | 手动创建（三步向导，含召唤快速问题配置）/ 已有接入（第三方）/ 自然语言创建（研发中，占位） |
| 召唤 | 卡片「召唤」或详情页（常驻，默认浅色，悬停卡片切主色） | 跳转新建任务页，输入框底部携带该助理；「+」可切换；欢迎区展示该助理配置的快速问题；已拒绝 / 已下架 / 下架审批中均仅创建人可召唤（试用） |
| 共享助理 | 左侧「共享助理」页签 | 展示别人共享给我的助理（已订阅 + 已移除），可切换筛选；支持移除与重新订阅 |
| 查看详情 | 卡片标题或「详情」 | 基础信息 / 能力组成 / 授权范围 / 版本记录；已拒绝助理详情与已共享一致（「下架」位置换成「重新提交」，删除始终展示、点击后按状态判定）；已下架助理底部为「编辑 / 重新共享 / 删除 / 关闭 / 召唤」 |
| 编辑 | 详情页「编辑」 | 审批中（共享 / 调整 / 授权 / 下架审批）与已拒绝不展示编辑；已共享过的助理保存后提交变更审批，审批通过时版本号尾号 +1；未共享与已下架编辑直接生效，不产生版本号、不改变状态 |
| 重新提交 | 已拒绝助理详情「重新提交」 | 已拒绝 · 授权审批 → 范围授权页（回显上次授权范围）；已拒绝 · 共享审批 / 调整审批 / 下架审批 → 编辑页（回显当前配置），保存即提交新一轮审批 |
| 删除 | 未共享 / 已拒绝（共享审批）/ 已下架（创建人，不受曾共享限制） | 二次确认后删除；已共享过（调整审批 / 授权审批 / 下架审批被拒）不可删除，提示「该助理已共享过，无法删除，请进行下架处理」 |
| 下架 | 已共享卡片「下架」 | 填写下架原因 → 提交下架申请 → 管理员审批 |
| 授权范围 | 已共享 / 已拒绝卡片 / 详情 | 管理员改动立即生效；已拒绝助理的创建人可「修改授权范围」，提交后状态变为「审批中 · 授权审批」，通过后按新范围完成共享；创建人改动后状态变为「审批中」（审批期间原授权范围继续生效），审批通过按新范围展示且版本号尾号 +1；审批拒绝则状态变为「已拒绝 · 授权审批」，仅本次变更不生效，原共享范围与已订阅用户不受影响，可重新提交 |
| 审批中心 | 管理员视角右上角 | 共享申请 / 授权申请 / 调整申请 / 下架申请 四类，类型标识与审批单类型一一对应，可调整授权范围后通过或拒绝 |

## 数据约定

- 助理状态：`unshared` 未共享、`pending` 审批中（`pendingType` 区分 `share` 共享审批、`change` 调整审批、`scope` 授权审批、`offline` 下架审批）、`approved` 已共享、`rejected` 已拒绝、`offline_pending` 下架审批中、`offline` 已下架、`platform` 平台内置
- 审批中角标与已拒绝同构，带子类描述：`审批中 · 共享审批 / 审批中 · 调整审批 / 审批中 · 授权审批 / 审批中 · 下架审批`
- 已拒绝描述 `rejectType`：`share` 共享审批（首次共享被拒，可删除）、`change` 调整审批（内容变更被拒，不可删除）、`scope` 授权审批（授权范围变更被拒，不可删除）、`offline` 下架审批（不可删除），角标展示为 `已拒绝 · {描述}`；`hasShared` 标记是否曾共享过；拒绝原因不在卡片展示，仅在详情中查看
- 来源：`custom` 手动创建、`thirdparty` 第三方接入、`platform` 平台内置、`shared` 被授权共享
- 版本：`version` 当前版本号（首次共享审批通过记 `V1.0.0`，此后每次变更 / 授权范围变更 / 已下架重新共享审批通过尾号 +1，到 99 进位，如 `V1.0.99` → `V1.1.0`；审批中、编辑保存、审批被拒绝、下架生效均不改版本号，未生成过版本显示「未发布」），`history` 版本与操作记录
- 页签构成：仅「全部 / 我的助理 / 共享助理」三个页签；全部 = 平台内置 + 已共享 + 已订阅三种状态，「已共享」含创建人已提交审批中的助理（共享 / 调整 / 授权 / 下架审批）与已拒绝的助理，但不含「已拒绝 · 共享审批」（该助理从未共享成功，仅在我的助理展示）；我的助理 = 我创建的全部助理（已共享 → 审批中（含下架审批中）→ 已拒绝 → 未共享 → 已下架）；共享助理 = 别人共享给我的（已订阅 + 已移除）
- 角标口径：「全部」范围只展示三种状态——平台内置「敬请期待」/ 自建与第三方接入「已共享」/ 共享助理「已订阅」，审批中与已拒绝同样显示「已共享」，不展开明细子类；「我的助理」范围展示「审批中 · 子类」「已拒绝 · 子类」
- 审批单类型：`share` 共享申请、`scope` 授权申请、`change` 调整申请、`offline` 下架申请
- 状态筛选：「我的助理」下拉固定 6 项（全部 / 未共享 / 已共享 / 审批中 / 已拒绝 / 已下架）；「审批中」聚合共享审批、调整审批、授权审批、下架审批；「已拒绝」聚合共享审批、调整审批、授权审批、下架审批（拒绝子类）
