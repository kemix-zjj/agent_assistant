## 助理主流程

| 流程 | 入口 | 说明 |
| --- | --- | --- |
| 添加助理 | 右上角「添加助理」 | 手动创建（三步向导，含召唤快速问题配置）/ 已有接入（第三方）/ 自然语言创建（研发中，占位） |
| 召唤 | 卡片「召唤」或详情页 | 跳转新建任务页，输入框底部携带该助理；「+」可切换；欢迎区展示该助理配置的快速问题 |
| 共享助理 | 左侧「共享助理」页签 | 默认展示全部，可按「已订阅 / 已移除」筛选；支持移除与重新订阅 |
| 查看详情 | 卡片标题或「详情」 | 基础信息 / 能力组成 / 授权范围 / 版本记录 |
| 编辑 | 详情页「编辑」 | 已共享的助理保存后版本 +0.1 并重新提交审批；未共享直接升版本 |
| 删除 | 未共享 / 已拒绝 / 已下架 | 需二次确认，未共享才可删除 |
| 下架 | 已共享卡片「下架」 | 填写下架原因 → 提交下架申请 → 管理员审批 |
| 授权范围 | 已共享卡片 / 详情 | 管理员改动立即生效；创建人改动需提交审批 |
| 审批中心 | 管理员视角右上角 | 共享申请 / 下架申请 / 范围变更 三类，可调整授权范围后通过或拒绝 |

## 数据约定

- 助理状态：`unshared` 未共享、`pending` 待审批、`approved` 已共享、`rejected` 已拒绝、`offline_pending` 下架审批中、`offline` 已下架、`platform` 平台预置
- 来源：`custom` 手动创建、`thirdparty` 第三方接入、`platform` 平台预置、`shared` 被授权共享
- 版本：`version` 当前版本号（v1.0 起），`history` 版本与操作记录
