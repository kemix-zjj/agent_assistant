核心设计要点：

1. share_scope 是范围申请单，stage 三态（requested / adjusted / effective）记录范围从提交到生效的完整过程，只增不改。

2. share_scope_item 是范围明细，1 张申请单对应 N 行，按 dim（org / role / position / user）存储四维选择。

3. approval 是审批单，记录审批状态流转（pending → approved / rejected / terminated），approval_type 区分 share（首次共享）和 scope_change（范围变更）。

4. expert_grant 是授权名册，只在审批通过或管理员直改时，将 effective 单的维度明细按人展开写入，一人一行，带 grant_status（授权有效性）和 subscribe_status（被授权方订阅状态）两个正交维度。

5. 创建助理不共享时，不写任何共享表，绑定关系由 expert.owner_user_id 表达。
