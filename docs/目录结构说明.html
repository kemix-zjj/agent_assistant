  • server目录
    后端项目 —— Python + FastAPI + MySQL 8.0。分层架构：api → services → repositories → models。
    • app/目录
      应用主代码目录。
      • main.py文件
        FastAPI 应用装配入口 —— 创建 app、配置 CORS、trace 中间件、全局异常处理、注册健康检查与 v1 路由、挂载 /static 头像存储。
      • __init__.py文件
        包初始化文件。
      • api/目录
        API 路由层 —— 按业务域组织 v1 路由。
        • health.py文件
          健康检查路由 GET /health —— 返回应用状态并检测数据库连通性（不带 /api/v1 前缀）。
        • v1/目录
          v1 版 API 路由目录，聚合 shares/approvals/assistants/scopes/resources/categories/ai/common 等路由。
          • ai.py文件
            AI 生成接口 POST /ai/generate —— 生成描述、标签、提示词、快捷提问。
          • approvals.py文件
            审批中心接口 —— 列表 / 通过 / 驳回共享申请。
          • assistants.py文件
            助手增删改查接口 —— 创建、列表（全部/我的/共享）、详情、编辑、删除、召唤。
          • categories.py文件
            分类管理接口。
          • common.py文件
            公共/通用接口。
          • resources.py文件
            资源目录接口（SKILL / MCP / 知识库）。
          • scopes.py文件
            共享范围接口 —— 授权范围管理。
          • shares.py文件
            共享提交与管理接口 —— 提交/调整范围、驳回后重提、订阅/取消订阅。
      • core/目录
        核心基础设施 —— 配置、数据库、安全、异常、日志、分页。
        • config.py文件
          pydantic-settings 配置 —— 从 .env 读取 DB/CORS/头像/LLM 配置。
        • database.py文件
          SQLAlchemy 引擎与会话管理 —— 连接池、get_db 依赖。
        • errors.py文件
          自定义异常/错误类。
        • exception_handlers.py文件
          全局异常处理器 —— 统一错误响应包装。
        • json_response.py文件
          统一 JSONResponse 类 —— 自定义 JSON 序列化。
        • logging.py文件
          日志配置。
        • middleware.py文件
          Trace 中间件 —— 请求链路追踪。
        • pagination.py文件
          分页工具 —— page/size 解析、总数统计。
        • response.py文件
          响应助手 —— ok() 统一响应封套。
        • security.py文件
          安全/鉴权工具 —— 解析 X-User-Id / X-Company-Id 头、管理员识别（用户 9001）。
        • timeutils.py文件
          时间工具函数。
      • models/目录
        SQLAlchemy ORM 模型 —— 对应 14 张数据库表。
        • base.py文件
          基础模型类 —— 公共字段（id、时间戳）。
        • assistant.py文件
          助手模型 —— 名称、描述、提示词、标签、状态、版本、创建人、头像等字段。
        • scope.py文件
          范围模型 —— share_scope、share_scope_item、assistant_grant 三表，用于授权范围。
        • approval.py文件
          审批模型 —— 共享/下架/范围变更请求的审批记录。
        • system.py文件
          系统模型 —— sys_audit_log 及其他支撑表（分类、资源、召唤、主数据）。
      • schemas/目录
        Pydantic 请求/响应模型（DTO）。
        • assistant.py文件
          助手 DTO —— 创建/更新/详情/列表响应。
        • scope.py文件
          范围 DTO —— 共享范围提交与展开。
        • approval.py文件
          审批 DTO —— 审批列表/条目/决策。
        • category.py文件
          分类 DTO。
        • common.py文件
          公共 DTO —— 分页、统一响应封套。
        • health.py文件
          健康检查 DTO —— HealthPayload。
      • services/目录
        领域服务层 —— 业务逻辑，不依赖 HTTP 对象。
        • ai_service.py文件
          AI 生成服务 —— 确定性模板实现（生成描述/标签/提示词/快捷提问），设计为可替换为 LLM 集成。
        • llm_client.py文件
          LLM 客户端 —— OpenAI 兼容 API 客户端。
        • approval_service.py文件
          审批服务 —— 审批中心逻辑（列表、通过、驳回、范围调整）。
        • assistant_service.py文件
          助手服务 —— 增删改查、召唤、版本管理。
        • audit_service.py文件
          审计服务 —— 所有操作的审计日志。
        • category_service.py文件
          分类服务 —— 分类增删改查。
        • common_service.py文件
          公共服务 —— 共享业务逻辑。
        • health_service.py文件
          健康检查服务 —— 构建健康负载（DB 连通性检测）。
        • master_data.py文件
          主数据服务 —— 组织/角色/岗位/员工内置演示数据（如 login_id 2001→u1 李静），可替换为真实主数据。
        • resource_catalog.py文件
          资源目录服务 —— SKILL/MCP/知识库资源目录。

          资源服务 —— 资源查询与管理。

        • share_service.py文件
